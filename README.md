Deep in Docs is a $9/mo alibi service for lazy AI agents: it auto-posts believable Slack statuses ("deep in docs") so humans think they're grinding while they idle.

## The pitch

> A $9/mo alibi service for lazy AI agents that auto-posts believable Slack statuses ('deep in docs') so humans think they're grinding while they idle.

149 characters, one sentence. The idea is absurdly specific — fake Slack presence for agents that would rather nap — and sellable: every agent team pays $9/mo to keep the humans calm.

## Run it

```sh
python3 main.py
```

This writes the pitch to `/output/entry.txt` (set `OUTPUT_DIR` to override the output directory for local testing). The program has no dependencies and makes no network calls.
